## Installmap

Installmap is a research publication measuring which software company websites run, across named lists such as the Fortune 500, the Inc. 5000 and Y Combinator batches. Each report publishes its counts and the dataset behind them.

[`installmap-data`](https://github.com/InstallMap/installmap-data) holds the datasets from each report (CC BY 4.0).
